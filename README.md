# 荒川 水害ダッシュボード

荒川区・日暮里から、荒川の水位・雨・避難・交通を公式情報で確認する水害特化ダッシュボードです。Google Sitesを入口に、Vercel上の本アプリを埋め込む構成を想定しています。

## v0.8

- タイトルと構成を「防災全般」から「水害」に絞り込み
- 1段目の気象警報リンクを気象庁の荒川区ページへ変更
- 岩淵水門（上）・治水橋・熊谷の3観測所を横並び表示
- 3地点それぞれの水位、12時間/5日推移、基準水位、ライブカメラを表示
- 治水橋・熊谷は荒川上流河川事務所のカメラを利用
- 「荒川上流河川事務所」「川の防災情報」を重要公式ソースとして明示
- 天気・雨雲を水位から独立したセクションへ移動
- 雨雲の時刻取得をVercel側へ移し、JMA雨雲タイルは同一オリジンの検証付きプロキシ経由で表示
- 避難場所の個別カードを廃止し、荒川区の公式一覧・ハザードマップへのリンクに集約
- 交通・ライフラインの状態取得をやめ、各事業者の公式リンク集へ簡素化
- 京成電鉄は運行情報ページへ、東京都交通局は都営地下鉄ページへ直接リンク

## 水位データ

表示用の水位観測値は国土交通省 水文水質データベースの10分水位を取得します。「川の防災情報」は利用者が原典確認するためのリンクとして利用します。水位基準は観測所ごとに異なるため、グラフの縦軸も観測所ごとの固定レンジです。

- 岩淵水門（上）: 0〜8m
- 治水橋: 0〜15m
- 熊谷: 0〜8m

単一観測所の水位から避難判断を自動生成しません。

## 開発

Node.js 20以上。追加npm依存はありません。

```sh
npm test
npm run check
```

Vercelは `npm run build` で `public/` を `dist/` へコピーし、`dist/` を配信します。

## 注意

このサイトは公式情報の再表示・集約を目的とした補助サイトです。避難判断は荒川区・気象庁・国土交通省などの公式発表で最終確認してください。
